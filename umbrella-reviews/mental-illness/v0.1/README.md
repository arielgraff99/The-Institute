# Mental Illness Umbrella Review v0.1

This module starts from **mental illness as one umbrella entity** and recursively tests whether evidence supports division into distinct diseases, biological endotypes, dimensions/spectra, stages, treatment-response states, operational categories, or multiaxial combinations.

The historical disease-splitting framework v0.2 is read-only and defines the judging criteria. Existing depression and schizophrenia Institute modules are treated as downstream evidence, not as sources of new criteria.

## Seed-pass conclusion

A single-disease model of mental illness is not supported. The working root architecture is **COMPOSITE_MULTIAXIAL** with an etiologic peel-off layer, transdiagnostic liability/endotype structure, dimensional phenotypes, longitudinal trajectories/stages, treatment-response states, operational diagnoses and contextual modifiers.

This is a seed pass only. No global psychiatric taxonomy is frozen yet.
