# Search Provenance — Mental Illness Umbrella Review v0.1 Recursive Run

Run date: 2026-08-04

The recursive umbrella review used 12 web-search batches containing 72 explicit queries across six evidence branches. Queries were organized around the following search families:

1. Cross-disorder genomic structure, general psychopathology, HiTOP and transdiagnostic neurobiology.
2. Schizophrenia-bipolar boundary, schizoaffective reliability/stability, affective psychosis and transdiagnostic biotypes.
3. Internalizing structure across MDD, anxiety, PTSD, panic/fear and transdiagnostic treatment evidence.
4. Neurodevelopmental overlap and specificity across ASD, ADHD, Tourette, rare variation and diagnostic-boundary effects.
5. Compulsivity across OCD/OCRDs, anorexia/eating pathology, Tourette/repetitive behavior and grooming phenotypes.
6. Externalizing, substance-use, disinhibition, antagonism and personality pathology.
7. Etiologic psychiatric presentations: autoimmune, genetic, neurologic, metabolic/endocrine, infectious, toxic/substance and neurodegenerative causes.
8. Cross-branch contradiction and boundary searches.
9. Clinical-utility and treatment-selection searches.
10. Most-recent 45-day sentinel searches.
11. Systematic-review, reproducibility, clustering-failure and negative-control searches.
12. Focused falsification searches for each branch.

Six recursive cycles were adjudicated. The last material class change occurred in cycle 3. Cycles 4-6 produced no branch-level class change, meeting the prespecified three-no-change stopping rule.

This file records verified aggregate search telemetry and search families. It does not claim to preserve every query string byte-for-byte. Token use, monetary cost and wall time were not available as verified telemetry and are therefore not reported.
