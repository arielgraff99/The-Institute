# Depression Disease-Specific Review Module v2.0

Version 2.0 preserves v1.0 and implements five methodological upgrades as executable components:

1. treatment-course trajectory representation;
2. causal temporality engine;
3. pseudoresistance and alternative-cause engine;
4. MDD-wide endotype analysis independent of the TRD label;
5. non-psychiatric historical holdout sensitivity.

The historical v0.2 framework remains immutable. The non-psychiatric holdout is a separate sensitivity ruler (v0.2-H1), not a modification of v0.2.

The first v2.0 run extends the 30-record v1 sentinel ledger with five targeted 2025-2026 records chosen to test the new architecture. It remains a sentinel implementation run, not an exhaustive systematic review.
