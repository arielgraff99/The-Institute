# Depression Disease-Specific Review Module v1.0

This module consumes the frozen Historical Disease-Splitting Framework v0.2 as a read-only scientific ruler.

## First executable run

- 30 sentinel evidence records
- 28 study families after deduplication
- dual-track unrestricted vs higher-confidence adjudication
- class-specific gates for distinct disease, endotype, dimension/spectrum, stage, treatment-response state and operational category
- context/pseudoresistance analysis
- no modification of historical criteria

## Result

Preferred formulation: COMPOSITE_MULTIAXIAL. TRD is supported as an operational category; treatment-response state, dimensional and stage components are supported to varying degrees; candidate endotypes likely exist in subsets; one distinct TRD disease is not supported in this run.

## Important limitation

This is a sentinel implementation run, not an exhaustive systematic review.
