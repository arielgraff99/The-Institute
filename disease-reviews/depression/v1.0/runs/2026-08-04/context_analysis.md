# Context and pseudoresistance analysis

The depression module treats healthcare context as a modifier of observed treatment resistance rather than as intrinsic evidence of disease ontology.

Current sentinel evidence supports several pathways by which context can affect TRD assignment: inadequate dose/duration, nonadherence, pharmacokinetic variability, diagnostic error, provider pathway, delayed treatment, socioeconomic disadvantage, access to psychotherapy/augmentation/neuromodulation, and differences in local definitions or age-specific consensus.

Therefore an observed treatment failure can be clinically real while remaining etiologically ambiguous. Context can lower confidence that treatment failure proves a separate biological disease. It cannot by itself create positive evidence for a new disease entity.

The operational consequence is that all future full-run records should extract treatment adequacy, adherence, access, healthcare system, country, specialist availability, psychotherapy availability, neuromodulation availability, and delay to treatment whenever reported.
