# Schizophrenia Subtype Review Module v1.0

Executable disease-specific module using the frozen Historical Disease-Splitting Framework v0.2.

## Question
What forms of heterogeneity within schizophrenia survive historical disease-splitting criteria?

## Main result
Preferred representation: **COMPOSITE_MULTIAXIAL / HETEROGENEOUS_SYNDROME**.

- Traditional schizophrenia subtypes: not supported.
- TRS: supported as treatment-response/operational state, not distinct disease.
- Clozapine resistance: nested treatment-response state.
- Deficit/primary negative phenotype: partially supported clinical subtype/dimension.
- Cognitive subtypes: partially supported dimensional phenotypes.
- B-SNIP psychosis Biotypes: strongest provisional biological endotypes, but transdiagnostic rather than schizophrenia-specific.
- Immune/inflammatory endotypes: provisional.
- Neuroimaging-only subtypes: insufficiently reproducible.

Target-family holdout excludes schizophrenia/psychosis historical comparators and leaves the result unchanged.
